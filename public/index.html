What QuoteScout surfaces in every RFQ

Four kinds of risk show up in almost every precision RFQ. We organize them by how urgently you should act.

RED

Must resolve before quoting

Things that can't be priced around — impossible operation sequences, missing required certifications, contradictions between drawing and spec. Fix these first or no-bid.

AMBER

Capability check needed

Requirements your shop may not currently support — quality certifications (ISO 9001, AS9100, IATF 16949, ISO 13485, API Q1, ASME), process accreditations (NADCAP), cybersecurity (NIST 800-171, CMMC), source-inspected processes, customer-approved vendor lists. Confirm before committing.

YELLOW

Hidden costs

Operations the drawing assumes but doesn't explicitly list — stress relief, post-coat machining, hand deburr, FAI prep, 100% inspection. Easy to skim past, expensive to absorb.

PURPLE

Verify before action

When the AI isn't fully confident, you see PURPLE. Specific items to confirm with engineering or the shop floor before committing. We tell you what we don't know.

FAQ

Is this really free?

Yes — for the first 500 shops. We're in free beta to validate the value before charging. After 500 shops, we'll introduce paid tiers. Founding members from the beta get a permanent discount.

What file types do you accept?

Most common RFQ-package formats — PDF, images, DXF, STEP/STP, IGES/IGS, STL/OBJ/3MF, Parasolid, SolidWorks (.sldprt/.sldasm), Inventor, Creo, CATIA, AutoCAD DWG, Fusion 360, G-code, and BOM spreadsheets (Excel/CSV). The depth of analysis depends on the format: PDFs and images get full vision analysis; DXF, STEP, and IGES are parsed for header metadata and text content; native binary CAD (SLDPRT, .ipt, .CATPart, .dwg, etc.) yields only metadata + embedded strings — so if you upload only a native CAD file with no PDF drawing, the AI will flag that visual confirmation isn't possible from binary geometry alone. Best practice: send a PDF drawing alongside any native CAD file.

How is this different from ChatGPT?

ChatGPT extracts text. QuoteScout has a manufacturing-specific risk taxonomy and prompt layer built around precision-machining failure modes ChatGPT doesn't know about. Every flag carries a confidence score and a category — Sequence Violation, Hidden Operation, Compliance Gap, Dimensional Compensation — so you can verify systematically rather than re-reading the whole document.

What's a "shop profile" and do I need one?

Optional but worth two minutes. You describe your shop's machines, certs (held and not held), AVL, capacity envelope, and shop rate range — and the AI switches from generic risk-listing to gap analysis. Flags become "your shop holds AS9100, confirmed in scope" or "your CMM travel (700×1000×600 mm) won't cover this Ø1254 mm part — sub-tier inspection required." Cost estimates use your real shop rate. What if your AI is wrong?

Every flag has a confidence score. Anything below 70% confidence shows as PURPLE with a "verify with shop floor" prompt. Every output ends with a mandatory disclaimer: "All flags require verification by qualified engineering personnel before pricing." You stay in control.

Can I use this for defense work?

No — ITAR / EAR / MIL-SPEC defense work is explicitly prohibited in V1. The system actively blocks RFQs containing those markers. We'll add ITAR-cleared infrastructure in Phase 4 (Month 18+).

I'm worried about uploading proprietary drawings. What protects me?

(1) Click-to-sign Mutual NDA before upload. (2) Files deleted within 60 seconds — never stored. (3) Database stores only metadata (filename, size, flag count). (4) HTTPS/TLS in transit. (5) No third-party sharing or model training. If you want to test before uploading anything sensitive: send a public RFQ from a request-for-proposal listing site to start.
