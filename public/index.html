FAQ

Questions estimators actually ask.

Is this really free?
Yes — for the first 500 shops. We're in free beta to validate the value before charging. After 500 shops we'll introduce paid tiers. Founding members from the beta get a permanent discount.
What file types do you accept?
Most common RFQ formats — PDF, images, DXF, STEP/STP, IGES/IGS, STL/OBJ/3MF, Parasolid, SolidWorks (.sldprt/.sldasm), Inventor, Creo, CATIA, AutoCAD DWG, Fusion 360, G-code, and BOM spreadsheets (Excel/CSV). Depth depends on format: PDFs and images get full vision analysis; DXF, STEP, and IGES are parsed for header metadata and text; native binary CAD yields only metadata + embedded strings — so if you upload only a native CAD file with no PDF drawing, the AI flags that visual confirmation isn't possible from binary geometry alone. Best practice: send a PDF drawing alongside any native CAD file.
How is this different from ChatGPT?
ChatGPT extracts text. QuoteScout has a manufacturing-specific risk taxonomy and prompt layer built around precision-machining failure modes ChatGPT doesn't know about. Every flag carries a confidence score and a category — Sequence Violation, Hidden Operation, Compliance Gap, Dimensional Compensation — so you verify systematically instead of re-reading the whole document.
What's a "shop profile" and do I need one?
Optional but worth two minutes. You describe your machines, certs (held and not held), AVL, capacity envelope, and shop rate — and the AI switches from generic risk-listing to gap analysis. Flags become "your shop holds AS9100, confirmed in scope" or "your CMM travel won't cover this Ø1254 mm part — sub-tier inspection required." Cost estimates use your real shop rate. Stored only in your browser via localStorage — never on our servers until you submit an analysis. Set up your profile →
Who built this?
Sid K. I work in precision-manufacturing operations during the day. QuoteScout is what I build in the evenings and on weekends — the tool I wish I'd had on my own desk. Every flag in the system is calibrated against a real miss I've seen on a real shop floor.
What if your AI is wrong?
Every flag has a confidence score. Anything below 70% shows as PURPLE with a "verify with shop floor" prompt. Every output ends with a mandatory disclaimer: "All flags require verification by qualified engineering personnel before pricing." You stay in control.
Can I use this for defense work?
No — ITAR / EAR / MIL-SPEC defense work is explicitly prohibited in V1, and the system actively blocks RFQs containing those markers. ITAR-cleared infrastructure is a later-phase consideration.
I'm worried about uploading proprietary drawings. What protects me?
(1) Click-to-sign mutual NDA before upload. (2) Files deleted right after analysis — held only briefly in private storage, never retained. (3) Database stores only metadata. (4) HTTPS/TLS in transit. (5) No third-party sharing or model training. To test before uploading anything sensitive, send a public RFQ from a request-for-proposal listing site.
