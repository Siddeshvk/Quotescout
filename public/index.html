What QuoteScout surfaces in every RFQ

RED

Sequence violations & compliance gaps

Operations that physically can't happen in the order written. Missing certifications buried on page 42. Things that must be fixed before any price is written.

AMBER

Compliance gaps

Required certifications (AS9100, IATF 16949, NADCAP, DFARS) the RFQ assumes you hold. We surface them so you can confirm before committing.

YELLOW

Hidden cost risks

Implied operations not explicitly scoped — Stress Relief between roughing and finishing, Nital Etch after grinding, Deburr, 100% inspection. Quote them or eat them.

PURPLE

Low-confidence flags

When the AI isn't sure, you see PURPLE. Explicit prompt to verify with shop floor before any action. We never pretend to know what we don't.

FAQ

Is this really free?

Yes — for the first 500 shops. We're in free beta to validate the value before charging. After 500 shops, we'll introduce paid tiers. Founding members from the beta get a permanent discount.

What file types do you accept?

PDF only in V1. If you have a CAD model (STEP, DXF, SLDPRT), export it as PDF first — every CAD tool can do this in 2 clicks. Phase 2 will add native CAD support.

How is this different from ChatGPT?

ChatGPT extracts text. QuoteScout normalizes manufacturing risk into a structured taxonomy: Sequence Violation, Hidden Operation, Compliance Gap, Dimensional Compensation. Each flag has machine-readable detection logic — not AI guesswork. We also score confidence on every flag, so you know when to verify.

Who built this?

Sid K — 9+ years in precision manufacturing operations at Nissan, Magna, Maruti Suzuki, and BEML. PMP, CSSGB, GD&T, APQP/PPAP certified. This is the tool I wish I'd had when I was watching $12K titanium blocks get scrapped because nobody surfaced the sequence risk.

What if your AI is wrong?

Every flag has a confidence score. Anything below 70% confidence shows as PURPLE with a "verify with shop floor" prompt. Every output ends with a mandatory disclaimer: "All flags require verification by qualified engineering personnel before pricing." You stay in control.

Can I use this for defense work?

No — ITAR / EAR / MIL-SPEC defense work is explicitly prohibited in V1. The system actively blocks RFQs containing those markers. We'll add ITAR-cleared infrastructure in Phase 4 (Month 18+).

I'm worried about uploading proprietary drawings. What protects me?

(1) Click-to-sign Mutual NDA before upload. (2) Files deleted within 60 seconds — never stored. (3) Database stores only metadata (filename, size, flag count). (4) HTTPS/TLS in transit. (5) No third-party sharing or model training. If you want to test before uploading anything sensitive: send a public RFQ from a request-for-proposal listing site to start.
